# Data × MEAL Learning Journey

## About

This repository documents my 90-day learning journey exploring the intersection of **Data Science, Artificial Intelligence, Software Engineering, and Monitoring, Evaluation, Accountability and Learning (MEAL).**

I am a Computer Science graduate and Software Engineer with an interest in using technology and data to solve real-world problems, particularly in healthcare and development.

Rather than only collecting certificates, I am using this repository to learn in public, apply concepts through practical projects, and document what I discover along the way.

## Goals

Over the next 90 days, I aim to:

* Build a stronger foundation in MEAL and program evaluation
* Strengthen my Data Science skills
* Apply Python and data analysis to real-world datasets
* Build practical Data × MEAL projects
* Explore how data can support better decision-making and impact measurement
* Improve my ability to communicate technical ideas clearly
* Build a public portfolio for my future Data Science career

## Learning Areas

MEAL foundations, indicators, Theory of Change, data collection and data quality.

Work with public datasets and apply Data Science techniques to monitoring and evaluation problems.

Develop practical Data × MEAL projects and document the results.
